The problem

Operators learn a sterile procedure where mistakes contaminate product

New operators have to gown in the right order, check the room before entry, and swap a filling needle inside a RABS without breaking asepsis. The client wanted VR training for this, and had a Figma file of early screens: mixed Italian and English copy, a question that was unreadable at a 1:1 contrast ratio, 38 px buttons too small for a controller ray, and an instruction panel that jumped to a new position on almost every screen.

The confirmed flow covered only the happy path. Errors for picking a non-sterile needle, misaligning it or not locking it existed only as notes on a draft page. For a procedure where those mistakes are the reason to train, that was the biggest gap.

Process

From audit to headset, in nine steps

  1. Audit the Figma file

    Decoded the .fig file to inventory every screen, text style and colour. Measured contrast (one key question was at 1.0:1), flagged 41 one-off text styles and found the missing error paths.

  2. Write a copy deck

    One language, verb-first instructions, and a pair of messages for every outcome: success says why it matters, error says what to do next.

  3. Brief, spatial layout and user flow

    Defined users, objectives and constraints. Mapped the 13-step needle change into four phases, with a recovery path for each hands-on step.

  4. Redesign the screens

    Rebuilt the flow as 24 screens on a token-based UI kit, sized for the headset: 64 px targets, text at 22 px and up, AA contrast.

  5. Clickable prototype

    Generated a Figma plugin that builds the frames and wires 78 prototype links, plus a browser version for quick review.

  6. Unreal Engine 5 spec and integration

    A data-driven step table and string table, a C++ state machine, and world-space UMG widgets running in the client's UE 5.5 project.

  7. WebXR prototype

    Three.js and WebXR: floating task panels, cues on the real parts, Show me demos, assessment mode, and both flows from gowning to results.

  8. Bring in the real CAD

    Converted the client's five Unity FBX models into one optimised GLB, lined up to the trainee's side of the line.

  9. Declutter the spatial UI

    Folded the done message, controller hint and side panels into one compact card, with Steps and Help available on demand.

3D pipeline

Real equipment, light enough for a standalone headset

The FBX models came from a Unity project in mixed units, with every LOD level stored together and the operator doors modelled standing open. A browser-based converter drops the duplicate LOD, normalises everything to metres, turns the line so the HMI side faces the trainee, and cuts the open door bay out so animated doors can take its place. It then merges parts by material, welds and simplifies the heavy meshes, and compresses the result.

Spatial UI

One card per step, help on request

Early panels stacked phase chips, a counter, a toast, a hint pill and two side panels, so trainees had to read the UI before they could read the task. The final card shows one line of context, one instruction, and only the actions that step needs. Errors replace the instruction in the same place, so the trainee never loses their position.

Key decisions

What shaped the design

Guidance

Five layers of guidance, lightest first

Task card, then cues on the part, then feedback, then idle nudges, then Show me demos. Assessment mode switches off the cues, nudges and demos so the same build can train and test.

Errors

Every hands-on step can fail safely

Wrong packet, too early, misaligned, not locked: each has its own message and a retry in place, never a dead end.

Placement

The panel follows the work

The card floats about 1.1 m away, on the line of sight to the target and raised above it, so it never covers the part to touch.

Content

Data, not hard-coded screens

Steps, text and timings live in a table, so subject-matter experts can correct the procedure without touching code, in Unreal or on the web.

Outcome

A prototype stakeholders can run in a browser or headset

Both flows run end to end: gowning and the entry check, then the 13-step needle change on the real equipment. Everything ships as a single page and a 1 MB model, with the same step data driving the Unreal build.

Next
